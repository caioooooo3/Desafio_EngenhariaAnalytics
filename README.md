# Banking Analytics Dataset

Repository containing the datasets used in an Analytics Engineering challenge based on a banking domain.

## Available data

The repository includes relational and time-series datasets covering:

- agencies;
- clients;
- employees;
- employee-to-agency relationships;
- bank accounts;
- credit proposals;
- transactions;
- IPCA time series.

Examples of relational keys present in the files include cod_cliente, cod_agencia, cod_colaborador and num_conta.

## Files

~~~text
agencias.csv

dados_ipca.csv
~~~

## Status

This repository currently stores the **data assets only**. Analytical or engineering code is not versioned here, so it should be treated as a dataset repository rather than a finished portfolio project.
